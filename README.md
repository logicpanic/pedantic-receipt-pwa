# レシート送信 PWA

経費レシートをスマホで撮って、設定した送信先URLへアップロードするだけの静的ページ。

- 撮影 → 長辺2000pxへ圧縮 → 送信、以外のことはしない
- 送信先URLは各端末の localStorage にのみ保存され、このリポジトリにもサーバーにも保存されない
- 秘密情報は含まない（ホスティング用の公開コピー）

## 使い方

`https://<Pages URL>/#<送信先URL>` を開くと送信先が自動設定される。
ホーム画面に追加するとアプリとして起動する。
